# Idea Log

Toda idea nueva entra aquí antes de convertirse en alcance.

## Flujo

```text
Inbox → Exploring → Accepted → Planned
                 ↘ Rejected
                 ↘ Parked
```

Aceptar una idea exige vincularla a un problema, una épica y evidencia o hipótesis verificable. `Accepted` no significa prioridad inmediata.
