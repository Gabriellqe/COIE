# Sprints

## Sprint activo

- [[SPRINT-000]] — Project Foundation — `IN_PROGRESS`.

## Cadencia

La duración se decide al completar Foundation. Cada sprint debe contener:

```text
Goal
Selected User Stories
Tasks
Technical Notes
Results
Problems
Decisions
Next Actions
```

## Reglas

- un único objetivo cohesivo;
- alcance seleccionado desde [[BACKLOG]];
- criterios de salida observables;
- cambios de alcance registrados;
- review basada en evidencia;
- retrospectiva breve aunque el resultado sea incompleto;
- trabajo no terminado vuelve al backlog y no se marca parcialmente como `DONE`.

## Cierre

1. Ejecutar validaciones.
2. Revisar criterios y Definition of Done.
3. Registrar resultados y problemas.
4. Actualizar backlog, roadmap y changelog.
5. Registrar decisiones mediante ADR.
6. Crear retrospectiva y siguientes acciones.
