# Research Log

La investigación debe producir evidencia reutilizable y fechada, no sólo una conclusión.

## Estructura

- `markets/` — países, canales, monedas, tasas y restricciones.
- `niches/` — problema, demanda, competencia y profundidad de SKU.
- `products/` — identidad, comparables, economía y riesgos.
- `suppliers/` — ofertas, MOQ, lead time y confiabilidad.
- `conversations/` — síntesis conceptuales proporcionadas por el propietario y reconciliaciones; no son evidencia comercial externa.

## Requisitos de una nota

- alcance y pregunta;
- fecha y mercado;
- fuentes directas y fecha de consulta;
- hechos separados de inferencias;
- limitaciones y datos faltantes;
- conclusión provisional;
- relación con oportunidad, idea o decisión;
- criterio de frescura/revisión.

Una investigación vencida se conserva y se marca; no se reescribe como si siempre hubiera contenido datos nuevos.
