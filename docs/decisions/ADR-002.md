# ADR-002 — Mercado inicial Chile y moneda CLP

## Contexto

El Sprint 0 exige elegir mercado, país y moneda antes de crear fixtures, cálculos y contratos ejecutables. El primer caso propuesto son repuestos para motocicletas asociados a NK150.

## Decisión

- Mercado inicial: Chile.
- Código de país: `CL`.
- Moneda base: peso chileno (`CLP`).
- Zona horaria de presentación: `America/Santiago`; persistencia temporal en UTC.
- Primer caso vertical: reventa (`RESALE`) de un repuesto usado asociado a NK150.

El fixture inicial será sintético y no afirmará compatibilidad real. Repuestos nuevos orientados a recurrencia se evaluarán posteriormente bajo `REPLENISHMENT`.

## Alternativas consideradas

### Mantener mercado y moneda abstractos

Descartada porque impediría validar reglas monetarias, fixtures y experiencia de usuario.

### Iniciar simultáneamente en varios países

Descartada por ampliar conversiones, fuentes, términos y comparabilidad antes de validar el primer flujo.

## Consecuencias

- Los datos del incremento inicial se validan en `CLP`.
- Las interfaces muestran importes como pesos chilenos.
- La arquitectura sigue admitiendo otros mercados y monedas mediante entidades explícitas.

## Criterio de revisión

Revisar al preparar una expansión a otro país o cuando una oportunidad exija conversión de moneda.
