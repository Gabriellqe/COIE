# ADR-010 — Evidencia real aportada manualmente con retención mínima

## Contexto

[[ADR-003]] separó la fuente externa del método de ingreso y mantuvo `FND-007` abierto hasta comprobar un mecanismo real permitido. El 2026-08-19 el propietario aportó una extracción manual de resultados de Facebook Marketplace Chile, declaró autorización para su tratamiento interno y fijó la captura a las 15:00 en `America/Santiago` (`2026-08-19T19:00:00Z`).

La autorización declarada cubre el material aportado por el usuario. No constituye autorización de Meta para que COIE recolecte datos automáticamente ni cambia las restricciones documentadas en [[DATA-ACQUISITION-CL-2026-08-18]].

## Decisión

Se acepta `USER_PROVIDED_MANUAL_EXPORT → MANUAL_USER_ENTRY` como primer mecanismo real permitido de adquisición. Facebook Marketplace Chile se registra sólo como fuente de procedencia `MANUAL_ONLY`; no se marca como fuente autorizada para automatización.

Para esta captura se aplica lo siguiente:

- se registran únicamente títulos que declaran un kit de arrastre/transmisión y mencionan explícitamente `NK150`;
- se deduplica por `externalListingId` dentro de la captura;
- se conservan sólo ID/URL del listing, título visible, precio `ASKING` visible, moneda, fecha, método y flags de calidad;
- no se conservan imágenes firmadas/CDN, páginas completas, cookies, mensajes, ubicación precisa, perfil, contacto ni otros datos personales del vendedor;
- condición, variante, composición del kit y cantidad permanecen `UNKNOWN` si no están declaradas;
- compatibilidad `NK150` queda como `CLAIMED_UNVERIFIED`;
- precios cero, nominales o materialmente anómalos se registran para revisión, pero no entran a comparables;
- toda la captura queda en cuarentena y fuera de cohortes hasta resolver condición, variante, cantidad y precio;
- la evidencia estructurada mínima se revisa o elimina a los 90 días (`2026-11-17T19:00:00Z`).

El registro detallado permanece en almacenamiento local ignorado por Git. No se copia al fixture Foundation, al store DEMO ni a Supabase. La documentación versionada conserva sólo metadatos, conteos, política y conclusiones agregadas.

## Consecuencias

- `FND-007` puede cerrarse con el alcance preciso de **primer mecanismo real permitido** y no como autorización de plataforma.
- `DA-003` continúa `BLOCKED`: no se habilitan scraping, navegador automatizado, API privada, proveedor de scraping ni conector.
- La aplicación continúa en perfil Foundation DEMO. Promover evidencia real exige un contrato/almacén REAL separado y, antes del uso multiusuario, Platform Access con Auth/RLS según [[ADR-008]].
- La captura no demuestra ventas, demanda, velocidad, condición, compatibilidad verificada ni Market Value.

## Alternativas consideradas

### Ingresar las filas al store DEMO

Descartada porque mezclaría evidencia real con un contrato que exige `DEMO` y URLs ficticias.

### Considerar la declaración del usuario como autorización de Meta

Descartada. La autorización del aportante sólo permite procesar internamente el material que entregó; no concede permiso para recolectar desde la plataforma.

### Conservar el archivo y las imágenes completos

Descartada por minimización, caducidad de URLs firmadas y ausencia de necesidad analítica.

## Criterio de revisión

Revisar antes de promover una fila a evidencia REAL comparable, ampliar la retención, compartir los datos, activar un conector o al llegar `2026-11-17T19:00:00Z`, lo que ocurra primero.
