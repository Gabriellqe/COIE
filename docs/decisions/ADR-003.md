# ADR-003 — Adquisición inicial mediante carga manual trazable

## Contexto

Mercado Libre Chile y Facebook Marketplace son fuentes candidatas, pero el proyecto no dispone de API ni ha verificado todavía términos, automatización, límites o retención permitida. Que una página sea pública no demuestra autorización para automatizar su captura.

## Decisión

El primer método de ingreso será `MANUAL_USER_ENTRY`. Una persona registrará datos estructurados observados, incluyendo fuente, URL, título, precio, moneda, condición, tipo de precio y fecha.

Mercado Libre Chile y Facebook Marketplace se registran como fuentes candidatas de procedencia con estado `PENDING_TERMS_REVIEW`. No se implementará scraping, navegación automatizada ni almacenamiento de páginas completas durante Foundation.

La fuente externa y el método de ingreso se modelan por separado. Un dato ingresado manualmente no transforma la fuente en autorizada ni en venta confirmada.

## Alternativas consideradas

### Automatizar páginas públicas inmediatamente

Descartada por incertidumbre de permisos, fragilidad técnica y riesgo de construir el MVP sobre un acceso no comprobado.

### Esperar una API antes de desarrollar

Descartada porque contratos, fixtures, estadísticas y experiencia pueden validarse sin red.

## Consecuencias

- `FND-007` permanece abierto hasta comprobar una primera fuente real permitida.
- El sistema puede avanzar con fixtures DEMO e importación manual.
- Los conectores futuros implementarán el mismo contrato canónico sin mezclar adquisición y scoring.

## Criterio de revisión

Revisar cuando exista documentación de acceso, API, exportación o permiso verificable para una fuente real.
